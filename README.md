# BeQuant — local study build

A locally-run reconstruction of the **bequant.dev** quant-developer learning platform
(now offline), rebuilt from screenshots for personal exam prep. Four roadmaps,
142 lessons, deep-dive articles with curated reading + CppCon video links.

## Run it

You only need **Python 3** (already on macOS) — no Node, no build step.

```bash
cd site
./serve.sh            # runs server.py on :8000  (./serve.sh 9000 for another port)
```

Then open **http://localhost:8000**.

> ⚠️ Open it through the local server, **not** by double-clicking `index.html`.
> The app fetches `curriculum.json`, the Markdown lessons, and your saved state,
> which browsers block on `file://`.
>
> `server.py` both serves the site and persists your progress to a real file.
> (Plain `python3 -m http.server` still *works* but then progress is only kept
> in the browser's `localStorage`, not the on-disk file.)

## What's where

| Path | What |
|---|---|
| `site/server.py` | local server: serves the site + a `/api/state` endpoint that reads/writes `state.json` |
| `site/state.json` | **your progress + quiz results**, stored on disk (created on first save) |
| `site/index.html` · `app.css` · `app.js` | the single-page app (Overview → roadmap → lesson → dashboard → quiz) |
| `site/curriculum.json` | the full course structure (generated by `scaffold.py`) |
| `site/content/<roadmap>/<module>/<topic>.md` | one Markdown file per lesson |
| `site/assessments/<roadmap>.json` | the MCQ + coding-question bank for each track |
| `site/vendor/` | offline copies of the Markdown + syntax-highlight libraries |
| `curriculum.json` (repo root) | the hand-captured source of truth; edit this, then re-run `scaffold.py` |
| `scaffold.py` | regenerates `site/curriculum.json` + the content tree from the root `curriculum.json` |

## Features

- **Roadmaps as a DAG** — each track is a flow graph (nodes + curved connectors) showing
  the suggested learning order; click a module to see its lessons in the topics panel.
- **Mark complete** from the lesson page *or* the topics-panel checkmarks.
- **Persistent progress** — saved to `site/state.json` on disk via the local server
  (with a `localStorage` mirror), so it survives browser restarts, cache clears,
  and switching ports. Nothing leaves your machine.
- **Dashboard** (`#/dashboard`, or the top-nav link) — overall + per-track + per-difficulty
  progress, a module heatmap, day-streak, recent activity, strengths/focus areas,
  "continue where you left off", and **Export / Import / Reset** of your data.
- **Self-assessment** — per-module **MCQs** (auto-graded) and **runnable coding challenges**:
  write code in the editor, click **▶ Run tests**, and the app compiles + runs it against
  built-in test cases and shows a per-case pass/fail table. A heavily-commented reference
  solution stays hidden until you reveal it. Scores feed the dashboard.
- **Search** — press `/` anywhere.
- **Dark / light** theme toggle (◐, top right).

## Running code in coding quizzes

The coding challenges compile and run **locally** through `server.py`:

- **C++** is compiled with `clang++ -std=c++20` (Apple clang ships with the macOS
  Command Line Tools — already installed; no devops needed). Falls back to `g++`.
- **Python** runs with the system `python3` (stdlib-only solutions, so they always run).
- Each run is bounded by a timeout (so an infinite loop can't hang the server) and the
  server binds to `127.0.0.1` only — it executes code, so it is never exposed off-machine.
- If you start the site with plain `python3 -m http.server` instead of `server.py`, the
  **Run** button is disabled (no compile endpoint); lessons/quizzes still work.

## Backing up / moving your progress

Your data lives in `site/state.json`. Copy that file to back it up, or use the
dashboard's **Export** (downloads a JSON) and **Import** (restores from one).

## Adding or editing lessons

Edit the Markdown in `site/content/...`. A file that still begins with
`<!-- PLACEHOLDER -->` shows as "coming soon". Use fenced code blocks with a
language (` ```cpp `, ` ```python `, ` ```bash `, ` ```x86asm `) for highlighting.
